**NOTE: This release introduces a new preview size.**

- Added `x_grand` (1920x1920px bounding box) for social-media sharing
- Preview images are still not generated above the original file size. As a result, __only `maximum` (the original size) is guaranteed to exist__. The UI already falls back gracefully, but API consumers and direct media shortcut users (`/entries/ID/image.jpg?resolution=SIZE`) must handle missing sizes themselves.
- This change is applied to newly uploaded media only (no recalculation of previews for existing media)
