**NOTE: This release adds XMP sidecar import and tightens the no-upscale preview policy.**

- Media entries can import metadata from an `.xmp` sidecar (via incomplete entries / entry actions). Values are applied through IO mappings and **overwrite existing metadata** ([#974](https://github.com/Madek/Madek/issues/974)).
- Preview generation no longer upscales when the original is smaller than a target size — including portrait images and video stills. Missing sizes must be handled by the client, as with the 4.15 preview-size changes ([#474](https://github.com/Madek/Madek/issues/474)).
- IO mapping order is editable in admin; metadata import respects that order ([#960](https://github.com/Madek/Madek/issues/960)).
- Deploy: Transcrypt key rollover — secrets were re-encrypted; the new password is required to unlock them.
